# 🌐 Personal Website (Scrimba Exercise)

## 📖 Overview  
A simple **personal introduction webpage** built during a Scrimba HTML/CSS exercise.  
It includes a background image, fun facts, a LinkedIn link, and a newsletter subscription form.

---

## ✨ Features  
- 🎨 Custom background with vibrant imagery  
- 👤 Personal introduction section with name and fun facts  
- 🔗 LinkedIn connection link for networking  
- 📰 Newsletter subscription form with styled input and button  
- 📱 Responsive layout using CSS for scaling across devices  

---

## 🛠️ Technologies Used  
- HTML5 for structure  
- CSS3 for styling and layout  
- Flexbox for alignment  
- GitHub Pages for deployment  

---

## 🚀 Purpose  
The goal of this exercise is to practise:  
- Building a clean personal webpage  
- Experimenting with background images and text styling  
- Publishing projects live using GitHub Pages  

---

## 🔮 Future Improvements  
- Add more sections (projects, contact form)  
- Improve typography and font consistency  
- Enhance responsiveness for mobile devices
